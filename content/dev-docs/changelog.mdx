## The foundation release

The first chapter of Spark brings a clean, repository-powered home to your documentation.

- Dynamic product discovery from the content directory.
- JSON Schema and runtime-validated product configuration.
- Per-product accent colors, fonts, and branding.
- Collapsible navigation, product switching, and page search.
- MDX rendering and statically generated document routes.
- Responsive dark interface with keyboard-accessible controls.

## Up next

A local visual MDX editor with live preview, guarded filesystem saving, and version-aware documentation routing. These features are not part of the foundation release.
