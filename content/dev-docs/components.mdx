## The details, when you need them

<AccordionGroup>
  <Accordion title="Can I use my existing custom components?">
    Yes. The editor keeps unknown JSX intact. Existing Spark components have previews; other custom components appear as preserved placeholders. Register their trusted implementations in the docs renderer.
  </Accordion>
  <Accordion title="Does this run arbitrary JavaScript in the editor?">
    No. The editor parses MDX and previews literal component properties. Dynamic expressions and imports are preserved as source without being evaluated.
  </Accordion>
</AccordionGroup>
